MP4 and WebM play straight from their link, so IDM shows its “Download this video” bar. For .m3u8 streams, use Copy link and paste it in IDM. Files opened from your device cannot be downloaded.

Links, HTML code, BB code and embed code from file hosts can be pasted too. Pages that are not video files open inside the player, and “Open in tab” helps if a site blocks framing.

No sound on a file usually means an AC3/DTS audio track. Convert it with ffmpeg -i in.mkv -c:v copy -c:a aac out.mp4
